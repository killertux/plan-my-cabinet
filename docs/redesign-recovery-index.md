# Local recovery discovery integration

`RecoveryIndex` is opt-in and lives under the platform application user-data directory. Open it with `RecoveryIndex::open`; an absent index is empty, while a malformed, oversized, or unsupported index is reported and left untouched. It registers only explicitly identified documents: call `register_saved(path, project_id)` **after** a successful validated open/save, or `register_untitled(project_id)` for an unsaved editing session. Registration is atomic, bounded to 256 identities and 128 KiB, and never modifies the project or its snapshots. Canonical aliases share an identity; a copy at another path does not.

Continue using `RecoveryStore::note_committed_edit` and `tick` for saved projects. For untitled work, use the same 30-second committed-edit inactivity scheduling in the desktop event loop and call `write_untitled_snapshot(&index, &editor)`; it serializes only the committed editor model when dirty. Untitled records include an explicit `"saved_path": null` and a domain-separated UUID key. A later Save As does not silently transfer or delete this snapshot. `discover` examines only hash-derived files for registered identities and returns validated status, optional revisions and optional filesystem modification time. A missing saved document, invalid snapshot or future schema remains diagnosable and is never automatically deleted. No project directory is scanned.

Welcome should offer `Newer` saved snapshots and `Untitled` snapshots. At selection time, call `inspect_saved(path, id)` for saved projects; its candidate `resolve` retains the existing Recover/Defer/Discard behavior. Call `load_untitled(id)` for a revalidated pathless project, then route it through the unsaved-document/Save As lifecycle. In particular, `ProjectEditor::new` treats its input as a clean baseline; the UI integration for task 12.4 must explicitly represent an untitled recovered document as unsaved and require Save As. Never display a saved revision for an untitled snapshot or infer an export date from filesystem timestamps.
