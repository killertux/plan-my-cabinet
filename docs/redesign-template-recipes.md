# One-time template recipe geometry

`src/template_recipes.rs` produces candidate `Assembly` and ordered `Board` records. It does not change a project, assign stock, or create allocations. Callers supply existing or staged material IDs **and effective thickness snapshots** for each role. Shared IDs must have the same supplied thickness. Board identities are fresh on every call; board order is the ungrouped BOM and proposed first-fit order.

Coordinates use exact micrometres. Cabinet width is world X, front-to-back depth is Y, and height is Z. The carcass front plane is Y=0. Boards use their normal local X/Y/Z = length/width/thickness with rigid poses; root and child drawer assemblies have identity poses. All recipes include full-height side panels, horizontal panels between sides, and a full-width/full-height back overlaid behind the carcass. `outer depth = carcass depth + back thickness` for Base/Wall; Drawers also includes the exterior front thickness, which extends from Y=0 towards negative Y. The Drawers back plane is Y=`outer depth − external front thickness`, so the distance from the outside face of the front to the back plane equals outer depth.

- **Base:** bottom at Z=0; two rails of specified front-to-back width at the top, one at the front and one at the rear. The rail widths may meet but cannot overlap.
- **Wall:** bottom at Z=0, top at Z=`height - carcass thickness`, shelf underside at the supplied height strictly between the fixed panels.
- **Drawers:** same carcass as Wall without shelf. Opening width = outer width − 2 × carcass thickness; box width = opening width − 2 × side clearance. Each drawer occupies one equal-height opening between the bottom/top panels. The box footprint begins at the left clearance and Y=0; its underside is opening bottom + vertical clearance. The box height (including the applied bottom) is opening height − 2 × vertical clearance. Box sides sit on top of the full-footprint applied bottom; the front/back box members fit between the sides and span `box width − 2 × box thickness`. Box front/back thickness occupies Y=0..box thickness and Y=`box depth − box thickness`..box depth. Required rear clearance is measured between box end and carcass rear. Independent external fronts have X edge reveals; front height = `(outer height − 2 × perimeter reveal − (count − 1) × inter-front gap) / count`.

When openings or front heights do not divide evenly on the micrometre grid, the earliest drawers receive one extra micrometre each. This is exact partitioning, not silent numeric-unit rounding; the resulting individual board dimensions are available for review. Callers still own input-unit conversion and any required user rounding consent. Generated rectangles are starting arrangements, not machining, slide selection, load guidance, or certified mechanical fit.
